shiki-net

GitHub

shiki's JavaScript and TypeScript tokenizers as handwired neural networks, on your GPU through WebGPU. The page runs the network and shiki on the same code and compares their codeToTokens output. The full version is identical to shiki. The lite version is faster on long lines, and its tokens can differ from shiki's in rare cases.
